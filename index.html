Scrapy — Easy Learning Guide

A beginner-friendly guide to learning Scrapy step-by-step. Understand how Scrapy projects, spiders, requests, responses, selectors, crawling, pipelines and middleware work together.

1. What is Scrapy?

Scrapy is a Python framework used to build web crawlers and web scrapers.

Instead of manually writing requests and loops, Scrapy gives us a complete system for sending requests, receiving pages, extracting data and processing the results.

Simple idea: Scrapy = Request → Download → Parse → Extract → Process → Save

🌐 Request

Ask a website for a web page.

📄 Response

Receive HTML content from the server.

🔎 Selector

Find the required information.

💾 Pipeline

Clean and store scraped data.

2. Why Use Scrapy?

  • Fast web scraping
  • Concurrent requests
  • Automatic request scheduling
  • Retry support
  • XPath and CSS selectors
  • Pagination and link following
  • Item pipelines
  • Downloader middleware
  • Export to JSON, CSV and other formats
  • Large community and extensions
Scrapy is especially useful when your project needs to crawl many pages rather than just downloading one page.

3. Install Scrapy

First create a virtual environment:

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

Install Scrapy:

pip install scrapy

Check installation:

scrapy version

4. Create a Scrapy Project

Use the following command:

scrapy startproject bookscraper

Move inside the project:

cd bookscraper

Create a spider:

scrapy genspider books books.toscrape.com
Remember: Project = complete Scrapy application. Spider = individual crawler inside the project.

6. Spider

A spider contains the logic that tells Scrapy: where to start and what data to extract. 

import scrapy

class BooksSpider(scrapy.Spider):
    name = "books"
    allowed_domains = ["books.toscrape.com"]
    start_urls = ["https://books.toscrape.com/"]

    def parse(self, response):
        print(response.url)

Important attributes

  • name → unique spider name
  • allowed_domains → domains allowed for crawling
  • start_urls → initial URLs
  • parse() → default callback

7. Requests

A Request tells Scrapy which URL should be downloaded.

yield scrapy.Request(
    url="https://example.com",
    callback=self.parse
)

Scrapy schedules the request and downloads the page.

8. Response

After Scrapy downloads a page, the response object contains information about that page.

def parse(self, response):
    print(response.url)
    print(response.status)
    print(response.text)
Property Meaning
response.url Current URL
response.status HTTP status code
response.text HTML content
response.css() CSS selection
response.xpath() XPath selection

9. Callback

A callback is a function that Scrapy executes after a request receives a response.

yield scrapy.Request(
    url,
    callback=self.parse_product
)

def parse_product(self, response):
    print("Product page received")
Think of callback as: "When the page arrives, run this function."

10. Selectors

Selectors are used to locate information inside HTML.

CSS

Easy and commonly used.

XPath

Powerful and flexible.

11. XPath

Example HTML:

<h1 class="title">
    Python Book
</h1>

Extract the text:

title = response.xpath('//h1[@class="title"]/text()').get()

Get multiple values:

titles = response.xpath('//h1[@class="title"]/text()').getall()
Method Purpose
.get() Get first result
.getall() Get all results

12. CSS Selectors

CSS selectors are usually easier for beginners.

# Get one title
title = response.css("h1.title::text").get()

# Get all titles
titles = response.css("h1.title::text").getall()

# Get href
url = response.css("a.product::attr(href)").get()
Use CSS when the HTML structure is simple. Use XPath when you need more complex relationships.

13. Items

Items provide a structured way to define the data you want to scrape.

items.py

import scrapy

class BookItem(scrapy.Item):
    title = scrapy.Field()
    price = scrapy.Field()
    rating = scrapy.Field()
    url = scrapy.Field()

Use the item inside your spider:

item = BookItem()
item["title"] = title
item["price"] = price

yield item

14. Pagination

Pagination means moving from page 1 → page 2 → page 3...

next_page = response.css("li.next a::attr(href)").get()

if next_page:
    yield response.follow(
        next_page,
        callback=self.parse
    )
This allows Scrapy to automatically continue crawling additional pages.

15. Following Links

Scrapy provides response.follow() to conveniently follow links.

product_url = response.css("a.product::attr(href)").get()

yield response.follow(
    product_url,
    callback=self.parse_product
)

16. Multiple Start URLs

start_urls = [
    "https://example.com/page/1",
    "https://example.com/page/2",
    "https://example.com/page/3"
]

Scrapy will start requests for each URL.

17. Item Pipeline

Pipelines receive scraped items after they are produced by the spider.

Typical pipeline responsibilities:

  • Clean data
  • Validate data
  • Remove duplicates
  • Transform values
  • Save data to database
class BooksPipeline:
    def process_item(self, item, spider):
        item["title"] = item["title"].strip()
        return item

18. Export Scraped Data

Scrapy can export data directly.

scrapy crawl books -o books.json
scrapy crawl books -o books.csv
For small projects, Scrapy's built-in feed exports can be enough. For production systems, pipelines are often more useful.

19. Data Cleaning

Example:

title = response.css("h3 a::attr(title)").get()
title = title.strip()

Price conversion:

price = response.css(".price_color::text").get()
price = price.replace("£", "")
price = float(price)

21. Settings

Scrapy settings control how the scraper behaves.

# settings.py
ROBOTSTXT_OBEY = True
CONCURRENT_REQUESTS = 8
DOWNLOAD_DELAY = 1

FEEDS = {
    "data.json": {
        "format": "json"
    }
}
Do not blindly increase concurrency. Respect website policies and avoid unnecessarily aggressive traffic.

22. Concurrency

One of Scrapy's major advantages is that it can process multiple requests efficiently.

CONCURRENT_REQUESTS = 16

Higher concurrency can improve speed, but it should be balanced against server load and site restrictions.

23. Logging

Scrapy automatically provides useful logs while crawling.

scrapy crawl books

You can control logging:

LOG_LEVEL = "INFO"

Common levels:

  • DEBUG
  • INFO
  • WARNING
  • ERROR
  • CRITICAL

24. Dynamic Websites

Some websites use JavaScript to load information after the initial HTML response.

Static Page

Data exists directly in the HTML response.

Dynamic Page

JavaScript may load data after the page loads.

Scrapy itself is primarily an HTTP-based framework. For JavaScript-heavy pages, integrations such as Scrapy + Playwright can be used.

25. Scrapy + Playwright

Scrapy can be integrated with Playwright when browser rendering or interaction is needed.

Install:

pip install scrapy-playwright
playwright install

Example request:

yield scrapy.Request(
    url,
    meta={"playwright": True},
    callback=self.parse
)
Use browser automation when the required information cannot reasonably be obtained from normal HTTP responses.

26. Scraper Blocking

Websites may detect or restrict automated traffic.

Common causes include:

  • Too many requests
  • Unusual request patterns
  • Missing or inconsistent headers
  • IP restrictions
  • Bot detection systems

Responsible approaches include:

  • Respect robots.txt and site policies where applicable
  • Use reasonable request rates
  • Use appropriate headers
  • Implement retries carefully
  • Cache data when possible

27. Scaling Scrapy

Scrapy is designed for large crawling workloads and can be extended for distributed scraping.

Common scaling concepts:

  • Concurrency
  • Distributed workers
  • Queues
  • Persistent storage
  • Caching
  • Monitoring
Start with a simple spider. Scale only when the project actually needs more throughput.

30. Scrapy Best Practices

  1. Use meaningful spider names.
  2. Keep extraction logic simple.
  3. Use CSS/XPath selectors carefully.
  4. Validate extracted data.
  5. Use pipelines for cleaning and storage.
  6. Use reasonable concurrency.
  7. Handle pagination explicitly.
  8. Handle missing fields safely.
  9. Log important errors.
  10. Respect website terms and access policies.
